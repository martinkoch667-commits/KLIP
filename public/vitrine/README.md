# Visuels de la vitrine (page d'offre)

Les fichiers déposés ici s'affichent dans la rangée qui défile sur
`/onboarding/offre`. Aucune liste à tenir dans le code : la route
`/api/vitrine` lit ce dossier, donc **déposer le fichier suffit**.

## Ce qu'il faut déposer

| | |
|---|---|
| Format | **4:5 vertical** — 1080 × 1350 px (le format d'un post Instagram) |
| Type | `.jpg`, `.webp` (préférés), `.png`, `.avif` |
| Poids | **200 Ko maximum** par fichier. Au-delà, la page traîne à s'afficher |
| Nombre | **5 à 8**. Au-delà on ne les voit plus, en dessous la rangée paraît vide |

## Le nom décide de l'ordre

Numérotez : `01-burger.jpg`, `02-menu.jpg`, `03-terrasse.jpg`… L'ordre suit le
nom, donc renommer suffit à réorganiser la rangée.

## Ce qui marche le mieux dans cette rangée

- Des visuels **très différents les uns des autres** : une photo produit, un
  aplat typographique, un carrousel, une story. La rangée doit montrer l'étendue
  de ce que Klip sait faire, pas six fois la même composition.
- Du **texte lisible en petit** : les vignettes font environ 200 px de large à
  l'écran. Un titre qui remplit la moitié de la hauteur passe ; un paragraphe non.
- Des **chartes différentes** d'un visuel à l'autre : c'est ce qui prouve que
  l'outil s'adapte à chaque marque.

## Sans fichier ici

La page compose elle-même des visuels à la volée avec la charte du client, via
la vraie chaîne de production. C'est le comportement par défaut, et il reste le
bon tant que ce dossier est vide.
